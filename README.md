# Food_Delivery_Time_Prediction
Machine Learning project for predicting food delivery time
 Food Delivery Time Prediction

 Project Overview

A Machine Learning project that predicts the estimated food delivery time based on different input features.

 Objective

To develop a machine learning model that predicts food delivery time using regression algorithms.

 Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Streamlit

 Machine Learning Algorithms

* Linear Regression
* Decision Tree Regressor
* Random Forest Regressor

 Project Workflow

1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Model Training
5. Model Evaluation
6. Food Delivery Time Prediction

🌐 Web Application

An interactive Streamlit application that allows users to enter delivery details and get predicted delivery time.
